# 模式与框架库

## 框架：食品检验三步判定

拿到任何检验任务，先问三个问题：

1. 测什么：成分、添加剂、污染物、农兽药、微生物？
2. 用什么方法：标准法、快检、仪器确证？
3. 按什么判：产品标准、限量标准、方法标准？

三步走完，再谈操作。顺序反了，容易做了一堆数据却不会判。

## 框架：化学计算四步

1. 写已知量，统一单位；
2. 把质量/体积换成物质的量 n；
3. 按方程式系数比换成目标物质的 n；
4. 换回质量、浓度或质量分数，检查有效数字。

遇到多步反应，先写总反应或找关键计量关系，不要一步一步瞎乘。

## 框架：平衡移动判断

- 加反应物：向正反应方向移动；
- 加生成物：向逆反应方向移动；
- 升温：向吸热方向移动；
- 加压：向气体分子数减少方向移动；
- 加催化剂：不移动，只加快达到平衡。

具体到四类平衡，还要看平衡常数、Ksp、电极电势、稳定常数。

## 框架：检验结果异常回查

结果异常时，按顺序查：

1. 样品：采样是否代表、保存是否变质、制备是否均匀；
2. 前处理：提取是否完全、消解是否彻底、有无损失或污染；
3. 试剂：空白、标准品、有效期、配制是否正确；
4. 仪器：校准、状态、进样、色谱柱、检测器；
5. 计算：单位、系数、稀释倍数、有效数字；
6. 标准：方法依据、限量、判定规则。

不要一上来就怀疑仪器。大部分问题出在样品和前处理。

## 框架：营养标签阅读

1. 看每份还是每 100 g；
2. 看能量、蛋白质、脂肪、碳水、钠；
3. 看 NRV%；
4. 乘以实际吃进去的量；
5. 再判断“高蛋白”“低脂”“无糖”等声称是否成立。

标签是“每 100 g 的信息”，不是“整包的信息”。这是最常见的误读。

## 决策规则：快检阳性怎么办

- 快检阳性 → 标准方法复检 → 按限量判定；
- 快检阴性 → 记录结果，但不能排除未覆盖项目；
- 快检与标准法不一致 → 以标准法为准，查快检假阳性/假阴性原因；
- 重大活动保障 → 快检+实验室抽检组合，不能只靠快检。

## 反模式

- 只背标准编号，不记适用范围；
- 只背操作步骤，不理解为什么；
- 只做母题，不做变式；
- 只刷题，不回看错题原因；
- 只追求仪器高级，不管前处理和质量控制；
- 把“检出”当成“超标”，把“未检出”当成“零”。
