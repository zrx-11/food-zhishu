# 速查表

## 化学计量

| 场景 | 公式 |
|---|---|
| 物质的量 | $n=m/M$ |
| 粒子数 | $n=N/N_A$ |
| 气体体积 | $n=V/V_m$（标准状况 $V_m=22.4$ L/mol） |
| 浓度 | $c=n/V$ |
| 稀释 | $c_1V_1=c_2V_2$ |
| 质量分数与浓度 | $c=1000\rho w/M$ |
| 滴定 | $c_1V_1/n_1=c_2V_2/n_2$ |

## 四大平衡

| 场景 | 公式/规则 |
|---|---|
| 水的离子积 | $K_w=[H^+][OH^-]=1.0\times10^{-14}$ |
| pH | $pH=-\lg[H^+]$ |
| 弱酸 pH | $[H^+]\approx\sqrt{K_ac}$ |
| 缓冲溶液 | $pH=pK_a+\lg([A^-]/[HA])$ |
| 溶度积 | $K_{sp}=[A^{n+}]^m[B^{m-}]^n$ |
| 沉淀判断 | $Q>K_{sp}$ 生成沉淀 |
| 电极电势 | $E=E^\circ+\frac{0.0592}{n}\lg\frac{[\text{氧化型}]}{[\text{还原型}]}$ |
| 电池电动势 | $E^\circ_{\text{池}}=E^\circ_{\text{正}}-E^\circ_{\text{负}}$ |
| 配位稳定常数 | $K_f=\frac{[\text{配合物}]}{[\text{金属离子}][\text{配体}]^n}$ |

## 分析化学

| 场景 | 公式/规则 |
|---|---|
| 绝对误差 | $\Delta x=x-\mu$ |
| 相对误差 | $E_r=\Delta x/\mu\times100\%$ |
| 标准偏差 | $s=\sqrt{\sum(x_i-\bar{x})^2/(n-1)}$ |
| RSD | $s/\bar{x}\times100\%$ |
| 吸光度 | $A=\varepsilon bc$ |
| 透光率 | $A=-\lg T$ |
| 加标回收率 | $(加标样测定值-原样测定值)/加标量\times100\%$ |

## 理化检验

| 项目 | 方法 | 关键点 |
|---|---|---|
| 水分 | 常压干燥、减压干燥、蒸馏、卡尔·费休 | 高糖高脂用减压 |
| 灰分 | 550 ℃ 灼烧 | 缓慢炭化，恒重 |
| 蛋白质 | 凯氏定氮 | 总氮×换算系数，乳 6.38、小麦 5.70 |
| 脂肪 | 索氏提取、酸水解 | 索氏测游离，酸水解测结合 |
| 还原糖 | 斐林试剂 | 水解后测总糖 |
| 总酸 | NaOH 滴定 | 按主要酸计 |
| 维生素 C | 2,6-二氯靛酚、HPLC | 避光、快速、酸性稳定 |

## 专升本答题

| 题型 | 策略 |
|---|---|
| 选择题 | 先排除明显错误，注意单位、限定词 |
| 计算题 | 写公式、代数据、带单位、查有效数字 |
| 简答题 | 先结论，再分点解释，最后举例 |
| 实验题 | 目的、原理、步骤、现象、结论 |
| 综合题 | 拆成小问，逐问得分 |
