# 综合检验建议

## 跨书任务 1：给一款酸奶做“营养 + 理化 + 微生物”三合一评价

涉及：精讲第 6—9、11 章；题库第 6—9、11 章。

要求：

1. 列出该酸奶的营养标签应标项目；
2. 选水分、蛋白质、脂肪、酸度、乳酸菌活菌数的检测方法；
3. 说明菌落总数、大肠菌群、霉菌酵母的卫生意义；
4. 写一段不超过 300 字的评价结论。

评分要点：

- 项目与方法对应正确；
- 区分营养指标与卫生指标；
- 结论有数据、有依据、有局限性。

## 跨书任务 2：给一款酱腌菜做添加剂与污染物判定

涉及：精讲第 9—10 章；无机及分析化学第 4—12 章；26 本知识库《食品理化检验技术》《食品检验操作技术规范》。

要求：

1. 查 GB 2760 中该类别允许的防腐剂、着色剂、甜味剂；
2. 查 GB 2762 中铅、砷、镉的限量；
3. 设计采样和前处理方案；
4. 说明如果快检阳性，如何用标准法确证；
5. 写判定结论。

评分要点：

- 标准编号与项目对应；
- 限量判定不混用；
- 快检与标准法定位清楚；
- 报告信息完整。

## 跨书任务 3：给一款糕点做丙烯酰胺与美拉德反应分析

涉及：精讲第 5、9、10 章；题库第 5、10 章。

要求：

1. 说明丙烯酰胺的形成条件；
2. 说明美拉德反应对色泽和风味的影响；
3. 提出 3 条降低丙烯酰胺的工艺措施；
4. 设计检测方案（前处理、仪器、标准曲线）。

评分要点：

- 机制清楚；
- 措施可执行；
- 方法与标准匹配。

## 跨书任务 4：给一家企业实验室做质控方案

涉及：精讲第 12 章；题库第 12 章；26 本知识库《食品试验设计与统计分析》《SPSS统计分析》。

要求：

1. 设计空白、平行、加标回收、质控样方案；
2. 说明 CMA 与 CNAS 的区别；
3. 画一张检验流程质控点图；
4. 写一份不合格结果的回查清单。

评分要点：

- 质控点覆盖采样、前处理、仪器、数据；
- 标准物质和加标回收使用正确；
- 回查顺序合理。
