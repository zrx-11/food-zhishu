# 食品类大方向：从化学基础到营养与检测

这不是把几本书堆在一起，而是把食品检验检测技术专业要用的四条线接起来：

- 化学基础：无机化学、分析化学；
- 食品科学：食品化学、食品营养；
- 检验检测：理化、微生物、仪器、快检；
- 法规质控：标准、限量、报告、实验室管理。

## 推荐学习顺序

| 阶段 | 学什么 | 为什么 | 检查点 |
|---|---|---|---|
| 0 诊断 | 精讲第 1 章；化学知枢第 0 章 | 先知道自己在哪 | 能说出检验三问和化学计算主线 |
| 1 化学地基 | 精讲第 2—4 章；《无机及分析化学》第 0—5 章 | 计算、平衡、滴定是后面所有方法的基础 | 精讲第 2—4 章自测 ≥4/5；化学第 0—5 章题 ≥70% |
| 2 食品与营养 | 精讲第 5—8 章 | 食品化学解释变化，营养解释意义 | 能算能量、读标签、解释 Aw/变性/氧化 |
| 3 检验方法 | 精讲第 9—11 章；题库对应章节 | 采样、前处理、理化、微生物、快检 | 每章 12 题 ≥70% |
| 4 数据法规与冲刺 | 精讲第 12 章；两本题库错题回链 | 会判、会写报告、会应试 | 整卷 ≥75% |

如果你化学几乎零基础，不要直接从第 9 章开始。先走阶段 1，把物质的量、pH、Ksp、电极电势、滴定计算过一遍。

## 专升本怎么用

以广西食品大类为例，专业课通常围绕 **无机化学、分析化学、食品营养与健康** 出题，公共课还有高等数学和英语。具体科目、分值、免试政策以当年招生文件为准。

- 无机化学：精讲第 2—3 章 + 《无机及分析化学》第 0—4 章；
- 分析化学：精讲第 4 章 + 《无机及分析化学》第 4—12 章；
- 食品营养：精讲第 6—8 章；
- 计算题：精讲第 2、4、6、8、9 章例题 + 题库计算题；
- 简答题：精讲每章“一句话核心”“常见误解”“复习锚点”。

题库按“考点—母题—变式”排。先做母题，再做变式，错题回到精讲对应章节，不要只背答案。
